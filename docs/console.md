# 控制台（浏览器 UI）

## 打开

`/account-console`（或 `node --no-warnings scripts/console.mjs`）会启动（或复用）本地服务，并输出：

```text
CONSOLE_URL:http://127.0.0.1:<port>/?t=<token>
```

**地址必须带 token**（不带会返回 403 提示页）。页面交给 Qoder 内置浏览器打开；加 `--browser`
才额外用系统默认浏览器打开。

页面加载后，服务端会用 token 换发一个 **HttpOnly、SameSite=Strict 的会话 cookie**，页面随即把
token 从地址栏抹掉（`history.replaceState`），所以：

- 浏览器历史里不再留带 token 的地址；
- 刷新页面仍可用（同一标签页凭 cookie 过鉴权，`sessionStorage` 里也留了一份 token 供 API 用）；
- 服务重启后 cookie 与旧 token 一起失效，要用新输出的地址重新打开。

## 页面能做什么

- 当前登录身份核对；槽位卡片支持切换、单独签到、重命名、覆盖、删除、**回退到上一代**。
- 每张卡片内嵌 **credits 到期分批条**：一格 = 一个到期批次，颜色按紧迫度。默认只留总量条，
  悬停或 Tab 聚焦任一格给出来源池、积分、精确到分钟的到期时间与还剩几天；批次表、额度池表、
  每日赠送规则与合计说明收在「明细」里默认折叠，点开才看。
- 条上方常驻提醒小标签：最近到期、今日未领、到期未定、已过期未扣完、额度用尽。收起明细也
  不会漏看。
- 保存当前账号为新槽位、一键全员签到、签到日志、快照档位开关、环境自检。
- **会话可见性面板**：基线存在 `sessionStorage`，切换后页面被重新加载也仍能对比；切换完成
  （或失败/超时）时前端会自动重测一次并给出「与切换前一致 / ±N 条变化」的标记；也可以手动点
  「记为切换前基线」。

页面是 `assets/console.html` 单文件，零外部依赖、离线可用；服务端每次请求现读该文件，
改前端不用重启服务。

## 服务生命周期

- **不常驻**：Qoder 连续 3 分钟不在运行，服务自行退出并删掉 `server.json`。阈值是
  `config.json` 的 `exitAfterNoQoderSec`（默认 180，**0 = 常驻**），控制台「快照策略」里可改；
  倒计时在页面顶部横幅显示，归零后页面会明说“服务已退出，重开 Qoder 再跑 `/account-console`”。
  **切换进行中豁免**：`switch.lock` 有效或切换子进程还活着时计时器清零。
- **别把服务当契约**：它是否随 Qoder 一起退出取决于 IDE 的 Job Object，不做承诺；真正可靠的
  是数据全在 `~/.qoder-account-manager/`，与服务无关。token 绑定进程，服务没换进程时老地址
  老 token 依旧能用；`--restart` 或重启机器才会变。
- 切换进行中，页面所有写操作按钮置灰（服务端同时返回 409），`--stop` 也会拒绝执行。
- 停止服务优先走 `POST /api/shutdown` 让进程自己退；只有服务卡死时才兜底按 `server.json`
  的 pid 结束，且结束前核对命令行确实是 `server.mjs`、启动时间与记录相符。**永远不要用
  `taskkill /IM node.exe`**——Qoder 自己的 `node.exe` 子进程会一起遭殃。

## 切换为什么能跨过 IDE 重启

`/api/switch` 以 detached 子进程跑 `switch.mjs`，输出写入 `switch.log` 供前端轮询；本服务
本身也是 detached 的，Qoder 重启后页面还能拿到进度（是否被 Job Object 回收取决于环境，数据
不受影响）。恢复流程把 `auth.v1.dat` 放在**第一步**并用同卷 `rename` 原子落地；因为各槽位的
`Local State` 字节完全相同，换账号实质等价于换这一个文件，所以任何中断点都只会得到“已切换”
或“尚未切换”，不存在半交换的损坏。

切换按钮为**勾选式二次确认**：当前账号、不兼容槽位、解不开的快照自动置灰；未勾选时主按钮
锁定，勾上后整块转绿并亮起。

## 失败与告警

- 页面顶部与卡片内会显示服务端返回的错误原文；CLI 与页面共用同一份 `status` 数据，显示异常时
  先用 `accounts.mjs status --json` 对照。
- 额度读取失败只影响额度块，不影响保存/切换/签到；企业版账号显示“额度在组织后台”并给详情页
  链接，不会伪造数字。
